One plain-text script. Slides, a handout, a web page and a brief for your coding agent, all from the same file.

Watch the 4-minute tour Read it as a handout View on GitHub

The tour is itself a talkfile. Press → to page, s for the presenter window, n for notes.

Why a talk should be text

Slide software is built for hands and mice. Animatic is built so a person and an agent can both write, check and rebuild the same talk.

Agents can work with it

A small, checked grammar. An agent writes the file, runs animatic-check, reads the findings and fixes them.

Media has a paper trail

Every picture is a card with credit, licence and how it was made. Checks catch the gaps before the room does.

One source, many exports

Slides, handout PDF, web page and agent brief cannot drift apart, because they are the same file.

Deterministic

The same file builds to the same bytes, so a diff of the output is a diff of your changes.

It reads like narration

Spoken words are the default text. A shot marker says where the picture changes. The words stay in the speaker notes and the handout, off the slide.

Running a workshop with agents?

Mark a slide with a waypoint and the deck publishes one word when you reach it. A hook on each participant's machine turns that word into a note for their coding agent, so anyone who fell behind finds out without asking. A working service and hook are in the repo.
