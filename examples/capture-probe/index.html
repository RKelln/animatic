How to make the deck itself a secure context

  1. Open the built deck from disk. file:// is a secure context, and the deck has no remote assets and no fetch calls, so it runs straight off the filesystem. This is the best option: nothing to serve, and it works with the venue wifi down.
  2. Serve it on the presenter's own machine. python3 -m http.server then open http://localhost:8787. localhost and 127.0.0.1 are secure contexts.
  3. Or keep the Tailscale workflow and allowlist the host. In about:config, set dom.securecontext.allowlist to the host (comma separated, no port). This relaxes a security preference on that machine, so it is the option to take last.

A plain http:// address on a LAN or Tailscale IP is not a secure context, which is what this page will tell you if you are reading it that way.
